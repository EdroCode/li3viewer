Estas páginas precisam do ficheiro completo. Com os dados de exemplo só há 2 grupos, por isso os números não representam a turma.

Passa o rato, toca ou usa as setas para ver os detalhes de cada teste.

Em cada teste ganha quem foi mais longe: executou com tudo certo, executou com erros, compilou, não compilou. Em caso de empate no estado, conta o número de queries certas.

Cada coluna é um teste. Em baixo, a média de queries certas conta os grupos que não compilaram como 0%.
